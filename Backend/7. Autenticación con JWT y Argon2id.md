# Autenticación con JWT y Argon2id

> [!tip] Contexto
> El sistema de auth tiene dos mitades: **verificar contraseñas** (Argon2id, vía `golang.org/x/crypto/argon2`) y **emitir/validar tokens** (JWT HS256, vía `github.com/golang-jwt/jwt/v5`). El middleware de Fiber protege rutas usando ambos en cadena → [[4. HTTP con Fiber v2]].

## 1. Hash y verificación de contraseñas (Argon2id)

Argon2id es el ganador del Password Hashing Competition y la **recomendación actual** (mejor que bcrypt/scrypt).

```go
package security

import (
	"crypto/rand"
	"crypto/subtle"
	"encoding/base64"
	"fmt"

	"golang.org/x/crypto/argon2"
)

// Parámetros recomendados (revisa las guías de OWASP)
const (
	timeCost     = 3
	memoryCost   = 64 * 1024 // 64 MB
	parallelism  = 2
	saltLength   = 16
	keyLength    = 32
)

func HashPassword(password string) (string, error) {
	salt := make([]byte, saltLength)
	if _, err := rand.Read(salt); err != nil {
		return "", err
	}

	hash := argon2.IDKey([]byte(password), salt, timeCost, memoryCost, parallelism, keyLength)

	// Formato autocontenido: versión$tiempo$memoria$paralelismo$salt$hash
	// (todo en base64 para poder guardarlo en una columna varchar)
	return fmt.Sprintf("$argon2id$v=%d$m=%d,t=%d,p=%d$%s$%s",
		argon2.Version, memoryCost, timeCost, parallelism,
		base64.RawStdEncoding.EncodeToString(salt),
		base64.RawStdEncoding.EncodeToString(hash),
	), nil
}

func VerifyPassword(password, encoded string) (bool, error) {
	// 1. Parsear el string guardado
	var version, memory, timeCost, parallelism int
	var saltB64, hashB64 string
	_, err := fmt.Sscanf(encoded, "$argon2id$v=%d$m=%d,t=%d,p=%d$%s$%s",
		&version, &memory, &timeCost, &parallelism, &saltB64, &hashB64)
	if err != nil {
		return false, err
	}

	salt, _ := base64.RawStdEncoding.DecodeString(saltB64)
	expected, _ := base64.RawStdEncoding.DecodeString(hashB64)

	// 2. Recalcular con los MISMO parámetros del string guardado
	actual := argon2.IDKey([]byte(password), salt, uint32(timeCost), uint32(memory), uint8(parallelism), uint32(len(expected)))

	// 3. Comparación en tiempo constante
	return subtle.ConstantTimeCompare(actual, expected) == 1, nil
}
```

> [!warning] `Subtle.ConstantTimeCompare`
> Nunca compares hashes con `==` o `bytes.Equal`: la comparación normal filtra información por tiempo. `ConstantTimeCompare` evita ataques de timing. Nunca cambies los parámetros de Argon2 a mitad del cifrado de un único hash — usa los guardados en el string.

## 2. Emisión y verificación de JWT (`internal/shared/jwt`)

```go
package jwt

import (
	"time"

	"github.com/golang-jwt/jwt/v5"
)

type Claims struct {
	UserID   uint   `json:"user_id"`
	TenantID uint   `json:"tenant_id"`
	Role     string `json:"role"`
	jwt.RegisteredClaims
}

type Manager struct {
	secret   []byte
	expHours int
}

func NewManager(secret string, expHours int) *Manager {
	return &Manager{secret: []byte(secret), expHours: expHours}
}

// Generate crea un token firmado con HS256
func (m *Manager) Generate(userID, tenantID uint, role string) (string, time.Time, error) {
	exp := time.Now().Add(time.Duration(m.expHours) * time.Hour)
	claims := Claims{
		UserID:   userID,
		TenantID: tenantID,
		Role:     role,
		RegisteredClaims: jwt.RegisteredClaims{
			Subject:   fmt.Sprintf("%d", userID),
			IssuedAt:  jwt.NewNumericDate(time.Now()),
			ExpiresAt: jwt.NewNumericDate(exp),
		},
	}
	token := jwt.NewWithClaims(jwt.SigningMethodHS256, claims)
	signed, err := token.SignedString(m.secret)
	return signed, exp, err
}

// Parse valida la firma, la expiración y devuelve los claims
func (m *Manager) Parse(tokenString string) (*Claims, error) {
	token, err := jwt.ParseWithClaims(tokenString, &Claims{}, func(t *jwt.Token) (any, error) {
		// defender la audiencia: solo HS256
		if _, ok := t.Method.(*jwt.SigningMethodHMAC); !ok {
			return nil, jwt.ErrSignatureInvalid
		}
		return m.secret, nil
	})
	if err != nil {
		return nil, err
	}
	claims, ok := token.Claims.(*Claims)
	if !ok || !token.Valid {
		return nil, jwt.ErrTokenInvalidClaims
	}
	return claims, nil
}
```

> [!tip] Luego de generar
> `Generate` devuelve la expiración para poder responderla y que el cliente sepa cuándo renovar. También se devuelve si se quiere invalidar token anterior (logout con blacklist en Redis → [[6. Caché con Redis]]).

## 3. Middleware de autenticación (`internal/shared/middleware`)

```go
func AuthRequired(m *jwt.Manager) fiber.Handler {
	return func(c *fiber.Ctx) error {
		// 1. Extraer el token del header
		auth := c.Get("Authorization")
		if !strings.HasPrefix(auth, "Bearer ") {
			return response.Error(c, fiber.StatusUnauthorized, "token_invalido", nil)
		}
		tokenStr := strings.TrimPrefix(auth, "Bearer ")

		// 2. Validar firma y expiración
		claims, err := m.Parse(tokenStr)
		if err != nil {
			return response.Error(c, fiber.StatusUnauthorized, "token_expirado_o_invalido", err)
		}

		// 3. Guardar claims en el contexto → el handler y el repo los usan
		c.Locals("userID", claims.UserID)
		c.Locals("tenantID", claims.TenantID)
		c.Locals("role", claims.Role)

		return c.Next()
	}
}
```

Los handlers leen la identidad:

```go
userID := c.Locals("userID").(uint)
tenantID := c.Locals("tenantID").(uint)
```

> [!warning] Autorización ≠ autenticación
> El middleware solo comprueba *quién es* (autenticación). Para *qué puede hacer* (autorización) se compara el rol en el service: `if claims.Role != "admin" { return 403 }`. Nunca confíes en el rol para lógica de negocio sin comprobarlo en cada operación sensible.

## Datos clave

- **Argon2id** para hash de contraseñas: salt aleatorio de 16 bytes + comparación en tiempo constante.
- Hash autocontenido en formato `$argon2id$v=19$m=65536,t=3,p=2$salt$hash`.
- **JWT HS256**: claims con `user_id`, `tenant_id` y `role`; firma verificada en cada request.
- Middleware `AuthRequired` extrae el Bearer, valida y puebla `c.Locals`.
- `tenant_id` del token → filtro de todas las queries en repos → [[5. Persistencia con GORM y PostgreSQL]].
- Secrets (`APP_JWT_SECRET`) siempre desde variables de entorno → [[2. Configuración con Viper]].
