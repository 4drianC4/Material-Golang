# Control de flujo

## Estructuras de control en Go (Condicionales y Bucles)
## **Conceptos**
Las **estructuras de control** permiten alterar el flujo de ejecución del programa dependiendo de condiciones o repeticiones. Go implementa estructuras de control simples, claras y eficientes.
Hay dos grandes grupos:
- **Condicionales**: evalúan condiciones para decidir qué ejecutar.
- **Bucles (loops)**: ejecutan un bloque de código repetidamente mientras se cumpla una condición.
## **Datos clave**
- Go **no tiene `while` ni `do...while`**, todo se hace con `for`.
- Las condicionales soportadas son: `if`, `else`, `if-else if`, `switch`.
- En Go no se necesitan paréntesis alrededor de las condiciones.
- Se pueden declarar variables justo antes de la condición (`if x := f(); x > 0 { ... }`).
## **Semántica / Estructura de Código**
### Condicional if, else, else if:
```
if edad >= 18 {
    fmt.Println("Mayor de edad")
} else if edad >= 13 {
    fmt.Println("Adolescente")
} else {
    fmt.Println("Niño")
}
```
### Bucle for
```
for i := 0; i < 5; i++ {
    fmt.Println(i)
}
```
### Bucle tipo while:
```
i := 0
for i < 5 {
    fmt.Println(i)
    i++
}
```
### Bucle infinito:
```
for {
    fmt.Println("Loop infinito")
    break
}
```
### switch:
```
switch dia {
case "lunes":
    fmt.Println("Inicio de semana")
case "viernes":
    fmt.Println("Fin de semana")
default:
    fmt.Println("Otro día")
}
```
### **Ejemplo**
```
package main

import "fmt"

func main() {
    edad := 20

    if edad >= 18 {
        fmt.Println("Eres mayor de edad")
    } else {
        fmt.Println("Eres menor de edad")
    }

    for i := 1; i <= 3; i++ {
        fmt.Println("Iteración:", i)
    }

    dia := "viernes"
    switch dia {
    case "lunes":
        fmt.Println("A trabajar")
    case "viernes":
        fmt.Println("A celebrar")
    default:
        fmt.Println("Día común")
    }
}
```
**Salida:**
```
Eres mayor de edad
Iteración: 1
Iteración: 2
Iteración: 3
A celebrar
```

## Uso del break y continue en bucles
## break
Se utiliza para salir inmediatamente del bucle en el que se encuentra.
```
for i := 0; i < 10; i++ {
    if i == 5 {
        break // Rompe el bucle cuando i es 5
    }
    fmt.Println(i)
}
```
**salida**:
```
0
1
2
3
4
```
## continue
omite la interacción actual del bucle y pasa a la siguiente.
```
for i := 0; i < 5; i++ {
    if i == 2 {
        continue // Salta esta iteración
    }
    fmt.Println(i)
}
```
**salida**
```
0
1
3
4
```
## **IMPORTANTE**
- Ambos se usan dentro de bucles for.
- break también puede usarse en switch dentro de bucles si es necesario forzar salida adicional.
- No existe goto-break como en otros lenguajes, pero Go sí tiene goto (aunque se desaconseja en la mayoría de los casos).
