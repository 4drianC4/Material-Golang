# Funciones

## **Conceptos**
Las funciones en Go son ciudadanos de primera clase: se pueden **declarar**, **asignar a variables**, **pasar como argumentos** y **retornar** como cualquier otro valor.
Hay distintos niveles de uso:
- **Declaración estándar:** funciones con nombre y parámetros.
- **Parámetros y valores de retorno:** Go permite múltiples valores de salida y retorno nombrado.
- **Funciones anónimas:** sin nombre, útiles para usos locales o puntuales.
- **Closures:** funciones que capturan variables de su entorno.
- **Funciones como valores:** asignadas a variables o pasadas como parámetros.

---

## **1. Declaración y uso**
```
func saludo(nombre string) string {
    return "Hola, " + nombre
}

mensaje := saludo("Juan") // llamada a la función
```
- `func`: palabra clave para definir funciones.
- `nombre string`: parámetro con tipo.
- `string`: tipo del valor de retorno.

---

## **2. Parámetros y valores de retorno**

## Múltiples parámetros del mismo tipo
```
func sumar(a, b int) int {
    return a + b
}
```
## Múltiples valores de retorno
```
func dividir(a, b int) (int, int) {
    return a / b, a % b
}
```
## Retornos nombrados
```
func datos() (nombre string, edad int) {
    nombre = "Ana"
    edad = 30
    return
}
```
---

## **3. Funciones anónimas y closures**

## Función anónima asignada a variable
```
saludo := func(nombre string) string {
    return "Hola, " + nombre
}

fmt.Println(saludo("Lucía"))
```
## Closure: función que recuerda su contexto
```
func contador() func() int {
    i := 0
    return func() int {
        i++
        return i
    }
}

c := contador()
fmt.Println(c()) // 1
fmt.Println(c()) // 2
fmt.Println(c()) // 3
```
- Cada llamada a `contador()` devuelve una nueva función con su propio valor interno de `i`.

---

## **4. Funciones como valores**
Las funciones pueden ser:
- Asignadas a variables
- Enviadas como argumentos
- Retornadas desde otras funciones
```
func aplicar(f func(int, int) int, a int, b int) int {
    return f(a, b)
}

func sumar(a, b int) int {
    return a + b
}

resultado := aplicar(sumar, 3, 4)
fmt.Println(resultado) // 7
```

---

## **Ejemplo completo**
```
package main

import "fmt"

func multiplicar(a, b int) int {
    return a * b
}

func operar(f func(int, int) int, x, y int) int {
    return f(x, y)
}

func main() {
    // Función estándar
    fmt.Println("Multiplicación:", multiplicar(2, 3))

    // Función anónima
    cuadrado := func(n int) int {
        return n * n
    }
    fmt.Println("Cuadrado de 4:", cuadrado(4))

    // Closure
    contador := func() func() int {
        i := 0
        return func() int {
            i++
            return i
        }
    }

    c := contador()
    fmt.Println("Contador:", c(), c(), c())

    // Función como valor
    resultado := operar(multiplicar, 5, 5)
    fmt.Println("Resultado de operar:", resultado)
}
```
**Salida esperada:**
```
Multiplicación: 6
Cuadrado de 4: 16
Contador: 1 2 3
Resultado de operar: 25
```
