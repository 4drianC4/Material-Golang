# Herramientas y Librerías Útiles

## **Conceptos**
El ecosistema de Go ofrece herramientas integradas y externas que facilitan:
- **Ejecución, compilación y pruebas**
- **Análisis estático del código**
- **Formateo y verificación**
- **Control de dependencias**
Estas herramientas son esenciales para mantener el código limpio, detectar errores tempranamente y automatizar tareas en proyectos reales.
## **Datos clave**
- Las herramientas estándar vienen con Go (`go run`, `go build`, `go test`, `go fmt`, etc.)
- Otras útiles se instalan con `go install` o `go get`
- Ayudan a mejorar la calidad y profesionalismo del código
    

---

## **Semántica / Herramientas clave**
## Comandos esenciales

|Comando|Función|
|---|---|
|`go run archivo.go`|Ejecuta un programa directamente desde el código fuente|
|`go build`|Compila el código y genera un binario|
|`go test`|Ejecuta pruebas de paquetes con funciones `Test*`|
|`go fmt`|Formatea el código automáticamente según la convención oficial|
|`go mod tidy`|Limpia y actualiza dependencias del `go.mod` y `go.sum`|

---

## Análisis estático del código

|Herramienta|Descripción|
|---|---|
|`go vet`|Detecta patrones sospechosos y errores sutiles|
|`golint`|Recomienda mejoras de estilo y convenciones|
|`staticcheck`|Superconjunto más potente: errores, estilo, prácticas inseguras|
```
go vet archivo.go
golint ./...
staticcheck ./...
```
> **`golint` y `staticcheck`** se instalan con:
```
go install golang.org/x/lint/golint@latest
go install honnef.co/go/tools/cmd/staticcheck@latest
```

## Otras herramientas útiles

| Herramienta     | Uso principal                                            |
| --------------- | -------------------------------------------------------- |
| `godoc`         | Servidor web para documentación generada desde el código |
| `gofmt -s`      | Formatea y simplifica código                             |
| `delve` (`dlv`) | Depurador interactivo para programas Go                  |
| `mockgen`       | Generación de mocks para pruebas con interfaces          |
| `go install`    | Instala herramientas desde paquetes externos             |
