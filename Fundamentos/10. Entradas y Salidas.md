# Entradas y Salidas

## **Conceptos**
Go proporciona múltiples herramientas para **leer y escribir datos** desde distintas fuentes: consola, archivos, redes, etc.  
Todo se basa en **interfaces de lectura y escritura**, como `io.Reader` y `io.Writer`.
También es muy común trabajar con **JSON**, y Go incluye el paquete `encoding/json` para convertir entre structs y texto JSON.
## **Datos clave**
- `os` → crea, abre y elimina archivos
- `bufio` → lectura eficiente desde consola o archivos
- `ioutil` (ahora `os` y `io`) → utilidades para lectura/escritura rápida
- `encoding/json` → codifica/decodifica JSON
- `fmt.Scan()` → entrada estándar (consola)

## **Semántica / Estructura de Código**

## Leer desde consola
```
var nombre string
fmt.Print("Ingresa tu nombre: ")
fmt.Scanln(&nombre)
fmt.Println("Hola,", nombre)
```
## Leer y escribir archivos
```
import (
    "os"
    "io"
)

func main() {
    // Crear archivo
    f, err := os.Create("saludo.txt")
    if err != nil {
        panic(err)
    }
    defer f.Close()

    f.WriteString("Hola desde Go\n")

    // Leer archivo
    data, err := os.ReadFile("saludo.txt")
    if err != nil {
        panic(err)
    }

    fmt.Println(string(data))
}
```
## Leer archivo línea por línea (bufio)
```
import (
    "bufio"
    "os"
)

func leerArchivoLineaPorLinea(nombre string) {
    f, _ := os.Open(nombre)
    defer f.Close()

    scanner := bufio.NewScanner(f)
    for scanner.Scan() {
        fmt.Println(scanner.Text())
    }
}
```

## **Ejemplo: Trabajar con JSON**

## Struct → JSON
```
import (
    "encoding/json"
    "fmt"
)

type Persona struct {
    Nombre string `json:"nombre"`
    Edad   int    `json:"edad"`
}

func main() {
    p := Persona{"Ana", 28}
    jsonBytes, _ := json.Marshal(p)
    fmt.Println(string(jsonBytes)) // {"nombre":"Ana","edad":28}
}
```
## JSON → Struct
```
var texto = `{"nombre":"Luis","edad":35}`
var p Persona
json.Unmarshal([]byte(texto), &p)
fmt.Println(p.Nombre, p.Edad)
```
