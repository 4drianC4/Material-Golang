# Buenas prácticas

## **Conceptos**
Go promueve un estilo de código **simple, claro y consistente**, enfocado en la **legibilidad**.  
La comunidad y las herramientas de Go hacen cumplir un conjunto de **convenciones oficiales**, lo que evita debates innecesarios sobre estilo y fomenta la colaboración.
Entre las buenas prácticas se incluyen:
- Nombrar correctamente variables, funciones y paquetes
- Comentar adecuadamente el código exportado
- Usar `go fmt`, `godoc`, `go vet`, entre otros 
## **Datos clave**
- `go fmt` → aplica formato estándar automáticamente
- `go vet` → analiza código en busca de errores sospechosos
- `godoc` → genera documentación a partir de los comentarios
- Se recomienda seguir las convenciones de nombres:
    - `CamelCase` para nombres exportados
    - `camelCase` para variables internas
    - nombres de paquetes **en minúscula**

---

## **Semántica / Estructura de Código**

## Formateo automático con go fmt
```
go fmt archivo.go
```
> Reorganiza importaciones, corrige sangrías, espaciado, etc.
## Convenciones de nombres
```
// correcto para código exportado
type Persona struct {
    Nombre string
}

// correcto para uso interno
var contador int
```
## Comentarios para documentación
```
// Saludar imprime un saludo con el nombre dado.
func Saludar(nombre string) {
    fmt.Println("Hola,", nombre)
}
```
> La primera línea del comentario **debe comenzar con el nombre del elemento documentado.**
## Documentación con `godoc`
```
godoc -http=:6060
```
Luego visita: [http://localhost:6060](http://localhost:6060)

## Buenas prácticas adicionales

|Categoría|Buenas prácticas recomendadas|
|---|---|
|Nombres|Paquetes en minúsculas, descriptivos (`saludar`, `utils`)|
|Funciones|Funciones pequeñas y con una sola responsabilidad|
|Errores|Siempre manejar errores retornados (`if err != nil { ... }`)|
|Paquetes|Organizar por funcionalidades, evitar ciclos de dependencias|
|Comentarios|Documentar solo lo necesario, evitar comentarios obvios|
|Código limpio|Evitar duplicación, usar constantes, eliminar código muerto|
