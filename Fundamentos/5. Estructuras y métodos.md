# Estructuras y métodos

## **Conceptos**
Un `struct` en Go es una estructura de datos compuesta que permite agrupar múltiples valores (campos) bajo un mismo tipo, ideal para representar **entidades** o **objetos**. Es comparable a una clase sin herencia.
Un **método** es una función asociada a un tipo (normalmente un `struct`) mediante un **receptor**. El receptor puede ser por **valor** o por **referencia (puntero)**.
### **Datos clave**
- Se declara con `type Nombre struct { ... }`
- Sus campos pueden ser accedidos con `objeto.campo`
- Los métodos permiten definir comportamientos asociados al struct
- Los receptores determinan si el método actúa sobre una copia o la referencia original
- No existe herencia, pero sí **composición**
- Los campos que empiezan en **mayúscula** son **exportados (públicos)**
#### **Qué es un receptor en Go?**
Un **receptor** es como un parámetro especial que se usa para asociar una función a un tipo (por ejemplo, un `struct`). Así, la función se convierte en un **método** de ese tipo.
La sintaxis general es:
```
func (r Tipo) NombreMetodo(...) TipoRetorno {
    // cuerpo del método
}
```
El receptor puede ser:
#### Receptor por valor
```
func (p Persona) Saludo() string {
    return "Hola, soy " + p.Nombre
}
```
 **Características:**
- Recibe una **copia** del objeto.    
- No modifica el objeto original.
- Útil para métodos **de lectura o presentación**.

**Consideraciones:**
- Cualquier cambio hecho dentro del método **no afecta** al struct original.
- Por **referencia (puntero)**: `func (r *Tipo)`
#### Receptor por referencia (puntero)
```
func (p *Persona) CumplirAnios() {
    p.Edad++
}
```
**Características:**
- Recibe una **referencia al objeto original**.
- Puede **modificar sus campos**.
- Útil para métodos que **cambian el estado** del struct.

**Consideraciones:**
- Permite trabajar con el mismo objeto sin copiarlo (más eficiente para objetos grandes).
#### **Reglas generales para usar cada uno**

|Caso|Recomendación|
|---|---|
|El método **no modifica** el struct|Usa receptor **por valor**|
|El método **modifica** el struct|Usa receptor **por referencia**|
|El struct es **grande** o pesado|Usa receptor **por referencia** para evitar copias|
|Consistencia en un tipo|Usa **siempre el mismo tipo** de receptor para todos sus métodos|

### **Semántica / Estructura de Código**
### Declaración de un struct
```
type Persona struct {
    Nombre string
    Edad   int
}
```
### Crear e inicializar
```
p := Persona{"Ana", 30}
q := Persona{Edad: 25, Nombre: "Luis"}
```
### Acceso a campos
```
fmt.Println(p.Nombre)
p.Edad = 31
```
### Método con receptor por valor
```
func (p Persona) Saludar() string {
    return "Hola, soy " + p.Nombre
}
```
### Método con receptor por referencia
```
func (p *Persona) CumplirAnios() {
    p.Edad++
}
```
## Ejemplo
```
package main

import "fmt"

type Persona struct {
    Nombre string
    Edad   int
}

// Método por valor
func (p Persona) Saludo() string {
    return "Hola, soy " + p.Nombre
}

// Método por referencia
func (p *Persona) CumplirAnios() {
    p.Edad++
}

func main() {
    p := Persona{"Carlos", 29}

    fmt.Println(p.Saludo())
    fmt.Println("Edad:", p.Edad)

    p.CumplirAnios()
    fmt.Println("Después de cumpleaños:", p.Edad)
}
```
**Con su salida esperada**
```
Hola, soy Carlos
Edad: 29
Después de cumpleaños: 30
```
