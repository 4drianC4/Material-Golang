# Interfaces

## **Conceptos**
Una **interfaz** en Go es un tipo que define un conjunto de métodos. Si un tipo (como un `struct`) implementa todos los métodos de una interfaz, **implícitamente satisface** esa interfaz.  
Go **no necesita palabras clave como `implements` o `extends`**. Basta con que el tipo tenga los métodos necesarios.
Las interfaces permiten **abstracción**, **polimorfismo** y una mejor separación de responsabilidades en el diseño de programas.
## **Datos clave**
- Las interfaces se declaran con la palabra clave `interface`.  
- Un tipo satisface una interfaz **automáticamente** si implementa sus métodos.
- Una interfaz puede tener **uno o más métodos**.
- La interfaz vacía `interface{}` acepta **cualquier tipo**.
- Interfaces se usan comúnmente con **valores dinámicos**, **funciones genéricas** y **composición de comportamientos**.
## Semántica / Estructura de código
## Declaración de una interfaz
```
type Animal interface {
    Hablar() string
}
```
## Implementación implícita por un struct
```
type Perro struct {
    Nombre string
}

func (p Perro) Hablar() string {
    return "Guau! Soy " + p.Nombre
}
```
## Uso de la interfaz
```
func decirAlgo(a Animal) {
    fmt.Println(a.Hablar())
}
```
---

## Ejemplo completo
```
package main

import "fmt"

// Interfaz
type Animal interface {
    Hablar() string
}

// Struct que implementa la interfaz
type Gato struct {
    Nombre string
}

func (g Gato) Hablar() string {
    return "Miau! Soy " + g.Nombre
}

// Otro struct
type Perro struct {
    Nombre string
}

func (p Perro) Hablar() string {
    return "Guau! Soy " + p.Nombre
}

// Función que usa la interfaz
func comunicar(a Animal) {
    fmt.Println(a.Hablar())
}

func main() {
    gato := Gato{"Luna"}
    perro := Perro{"Max"}

    comunicar(gato)
    comunicar(perro)
}
```
**Salida esperada**
```
Miau! Soy Luna
Guau! Soy Max
```
## Interfaz vacía (interface{})
La interfaz vacía puede contener **cualquier tipo** de valor. Se usa para manejar datos genéricos o dinámicos.
```
var algo interface{} = "Hola"
fmt.Println(algo) // Hola
```
## Uso con type assertion:
```
valor := algo.(string) // convierte interface{} a string
```
## Verificación segura con comma ok:
```
if str, ok := algo.(string); ok {
    fmt.Println("Es un string:", str)
}
```
### Extra: Interfaces personalizadas comunes
```
type Stringer interface {
    String() string
}
```
Si un tipo implementa String() string, se usa automáticamente al hacer fmt.Println().

## **Palabras Clave**

|Categoría|Palabras / Términos|
|---|---|
|Palabras reservadas|`type`, `interface`, `func`|
|Tipos de datos|`interface`, `interface{}`, tipos personalizados (`Perro`, `Gato`)|
|Funciones|métodos como `Hablar()`, `String()`, funciones que aceptan interfaces|
|Paquetes estándar|`fmt`|
|Términos importantes|interfaz, implementación implícita, polimorfismo, abstracción, `type assertion`, dinámico|
