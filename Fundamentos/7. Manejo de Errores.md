# Manejo de Errores

## **Conceptos**
En Go, el **manejo de errores es explícito**, simple y poderoso. A diferencia de otros lenguajes que usan `try/catch`, Go utiliza un enfoque basado en **valores de retorno**.  
Las funciones que pueden fallar retornan un valor de tipo `error`, y es responsabilidad del programador verificar y manejar ese error.
## **Datos clave**
- El tipo `error` es una **interfaz incorporada**:
	```
	type error interface {
	    Error() string
	}
	```
- Las funciones que pueden fallar retornan dos valores: el resultado y el error.
- Para crear errores personalizados se usa `errors.New()` o `fmt.Errorf()`.
- También existe el paquete `errors` en Go 1.13+ con `errors.Is()` y `errors.As()`.
- El manejo de errores mejora con `defer`, `panic` y `recover` para situaciones excepcionales.

---

## **Semántica / Estructura de Código**

## Retorno de error
```
func dividir(a, b int) (int, error) {
    if b == 0 {
        return 0, fmt.Errorf("no se puede dividir entre cero")
    }
    return a / b, nil
}
```
## Manejo del error
```
resultado, err := dividir(10, 0)
if err != nil {
    fmt.Println("Error:", err)
} else {
    fmt.Println("Resultado:", resultado)
}
```
## Crear errores personalizados
```
import "errors"

var ErrValorInvalido = errors.New("valor inválido")

func validar(n int) error {
    if n < 0 {
        return ErrValorInvalido
    }
    return nil
}
```
---

### 🔍 **Ejemplo completo**
```
package main

import (
    "errors"
    "fmt"
)

var ErrDivisionCero = errors.New("no se puede dividir entre cero")

func dividir(a, b int) (int, error) {
    if b == 0 {
        return 0, ErrDivisionCero
    }
    return a / b, nil
}

func main() {
    resultado, err := dividir(10, 0)
    if err != nil {
        fmt.Println("Ocurrió un error:", err)
        return
    }
    fmt.Println("Resultado:", resultado)
}
```
**Salida esperada:**
```
Ocurrió un error: no se puede dividir entre cero
```

## Extra: panic, defer y recover (para situaciones críticas)
```
func puedeFallar() {
    defer func() {
        if r := recover(); r != nil {
            fmt.Println("Recuperado de un error:", r)
        }
    }()

    panic("¡Error grave!")
}
```
- `panic()` interrumpe el flujo y lanza una excepción.
- `recover()` se usa en una función `defer` para atrapar ese `panic` y evitar que el programa termine abruptamente.
