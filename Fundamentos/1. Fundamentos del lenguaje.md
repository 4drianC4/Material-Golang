# Fundamentos del lenguaje

Go es un lenguaje **compilado**, **estáticamente tipado** y **conciso**: cada archivo debe tener una estructura clara y mínima para poder ejecutarse. Resuelve concurrencia y escalabilidad en sistemas modernos aplicando procesos a cada hilo, y es sencillo de aprender para backend, línea de comandos, apps web y cloud services.

## Primer programa en Go

### **Conceptos**
Un programa en Go está compuesto por **paquetes**, **funciones** y **sentencias** que se ejecutan en orden. Todo programa ejecutable debe comenzar en el paquete `main` y contener una función `main()` que actúe como punto de entrada.

Para crear un archivo se usa la extensión `.go`, por ejemplo `main.go` (el archivo que se encarga de correr todo el sistema).

### **Datos clave**
- El archivo debe comenzar con la declaración del paquete (`package main` para ejecutables).
- Se pueden importar paquetes con `import`.
- La función principal del programa es `func main()`.
- Las funciones y variables públicas deben escribirse con **mayúscula inicial** (visibilidad fuera del paquete).
- Go requiere que no haya **importaciones o variables no utilizadas**.

### **Semántica / Estructura de Código**
```
package main // Indica el paquete principal

import "fmt" // Importa el paquete fmt para imprimir en consola

func main() { // Función principal del programa
	fmt.Println("Hola mundo en Go") // Imprime un mensaje
}
```
- `package main`: se necesita para compilar un ejecutable.
- `import "fmt"`: trae el paquete estándar `fmt` que permite salida en consola.
- `func main()`: punto de inicio del programa.
- `fmt.Println(...)`: llama a una función para imprimir texto.

### 🔍 **Ejemplo**
```
package main

import "fmt"

func main() {
	fmt.Println("¡Bienvenido al mundo de Go!")
}
```
**Salida:**
```
¡Bienvenido al mundo de Go!
```

> [!tip] Primer proyecto real
> Para iniciar un proyecto se usa `go mod init nombreProyecto`, que crea el archivo `go.mod` (el primer módulo de una aplicación en Go, donde se indica la versión de Go usada). Todo esto se desarrolla en [[9. Módulos y Paquetes]].

## Tipos de datos en Go

### **Conceptos**
Los **tipos de datos** definen el tipo de valor que puede almacenar una variable. Go es **fuertemente tipado**: una vez declarada una variable con un tipo, no puede cambiarse. Las variables, además, tienen un **valor por defecto** (zero value) al declararse.

### **Tabla de tipos**

| Tipo | Descripción | Valor por defecto |
| --- | --- | --- |
| `bool` | `true` o `false`, para flags o condiciones | `false` |
| `string` | Cadenas de caracteres o texto | `""` (cadena vacía) |
| `int`, `int8`, `int16`, `int32`, `int64` | Enteros (se usa `int` por defecto; las demás variantes controlan el tamaño) | `0` |
| `uint`, `uint8`, `uint16`, `uint32`, `uint64` | Enteros positivos (cuando no se quiere un número negativo) | `0` |
| `float32`, `float64` | Números reales (decimales); 32 o 64 indica el tamaño | `0` |
| `byte` | Alias de `uint8`, para trabajar con datos binarios | `0` |
| `rune` | Similar a `int32`; representa un solo carácter que ocupa más de un byte | `0` |
| `complex64`, `complex128` | Parte real e imaginaria (`n + in`) | `0 + 0i` |

### **Tipos derivados**
Los tipos primitivos se combinan para formar tipos más complejos, que se estudian en sus propias notas:
- `array`, `slice`, `map` → [[4. Estructuras de Datos]]
- `struct` → [[5. Estructuras y métodos]]
- `interface` → [[6. Interfaces]]

## Variables y constantes

### **Conceptos**
Las **variables** son contenedores de datos que deben declararse antes de su uso. Go permite **declaración explícita** (especificando el tipo) e **inferencia de tipo** (dejando que el compilador deduzca el tipo con `:=`).

### **Datos clave**
- Las variables se declaran con la palabra clave `var`.
- También se pueden declarar e inicializar rápidamente con `:=`.
- Las variables no usadas provocan un error de compilación.
- Las variables declaradas a nivel de paquete deben tener un tipo explícito.

### **Semántica / Estructura de Código**
```
var edad int = 25       // Declaración explícita
nombre := "Adrian"      // Inferencia de tipo (string)

var (
  activo bool = true
  altura float64
)
```
- `var edad int = 25`: se especifica tipo y valor.
- `nombre := "Adrian"`: se infiere automáticamente que es tipo `string`.
- El bloque `var (...)` permite declarar múltiples variables agrupadas.
- `altura float64` se declara sin valor: toma su zero value (`0`).

### **Ejemplo**
```
package main

import "fmt"

func main() {
    var edad int = 25
    nombre := "Adrian"
    var altura float64 = 1.75
    var activo = true // también se puede inferir con `var`

    fmt.Println("Nombre:", nombre)
    fmt.Println("Edad:", edad)
    fmt.Println("Altura:", altura)
    fmt.Println("Activo:", activo)
}
```
**Salida:**
```
Nombre: Adrian
Edad: 25
Altura: 1.75
Activo: true
```

## Operadores y expresiones

### **Conceptos**
Un **operador** es un símbolo que indica al compilador que realice una operación matemática, lógica o de comparación. Una **expresión** combina variables, valores y operadores para producir un resultado.
Go proporciona varios grupos de operadores que siguen una **precedencia** (orden de evaluación) y una **asociatividad** (izquierda a derecha o viceversa).

### **Datos clave**
- **Operadores aritméticos**:
	```
	+, -, *, /, %
	```
- **Operadores de asignación**:
	```
	=, +=, -=, *=, /=, %=
	```
- **Operadores de comparación**:
	```
	==, !=, <, >, <=, >=
	```
- **Operadores lógicos**:
	```
	&&, ||, !
	```
- **Operadores unarios**:
	```
	++, --, -, +
	```
- No hay operador ternario (`?:`) en Go.
- Go no permite sobrecarga de operadores.

### 🧩 **Semántica / Estructura de Código**
```
a := 10
b := 3

suma := a + b         // Aritmético
igual := a == b       // Comparación
logico := a > 5 && b < 5 // Lógico
a++                   // Unario (incremento)
```
- Las expresiones combinan operadores con valores o variables.
- Go obliga a usar variables declaradas y tipos compatibles.

### **Ejemplo**
```
package main

import "fmt"

func main() {
    x := 8
    y := 3

    fmt.Println("Suma:", x + y)
    fmt.Println("Resta:", x - y)
    fmt.Println("Multiplicación:", x * y)
    fmt.Println("División:", x / y)
    fmt.Println("Residuo:", x % y)

    fmt.Println("¿x es igual a y?:", x == y)
    fmt.Println("¿x es mayor que y?:", x > y)

    fmt.Println("¿x > 5 y y < 5?:", x > 5 && y < 5)

    x++  // incremento
    y--  // decremento
    fmt.Println("x incrementado:", x)
    fmt.Println("y decrementado:", y)
}
```
**Salida:**
```
Suma: 11
Resta: 5
Multiplicación: 24
División: 2
Residuo: 2
¿x es igual a y?: false
¿x es mayor que y?: true
¿x > 5 y y < 5?: true
x incrementado: 9
y decrementado: 2
```
