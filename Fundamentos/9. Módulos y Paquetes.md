# Módulos y Paquetes

## **Conceptos**
En Go, el código se organiza en **paquetes** (`package`) y los proyectos modernos utilizan **módulos** (`go mod`) para gestionar dependencias, versiones y nombres de importación.  
Un **paquete** es una colección de archivos `.go` dentro de un mismo directorio que comparten un nombre de `package`.  
Un **módulo** es la unidad de gestión de dependencias y versiones, definida por un archivo `go.mod`.
## **Datos clave**
- Un paquete es todo lo que tiene la misma declaración `package nombre`.
- Un módulo se inicializa con `go mod init`.
- Los paquetes se importan con import "ruta/del/paquete".
- Los identificadores que empiezan con **mayúscula** son **exportados** (visibles desde fuera del paquete).
- Go busca dependencias en `https://proxy.golang.org`, y las gestiona en `go.mod` y `go.sum`.

## **Semántica / Estructura de Código**

## Crear un módulo
```
go mod init github.com/usuario/miapp
```
## Estructura de proyecto sugerida
```
miapp/
├── go.mod
├── main.go
├── saludar/
	   └── saludar.go
```
## Contenido de _saludar.go_
```
package saludar

import "fmt"

func Hola(nombre string) {
    fmt.Println("Hola,", nombre)
}
```
## Uso del paquete desde `main.go`
```
package main

import (
    "github.com/usuario/miapp/saludar"
)

func main() {
    saludar.Hola("Adrián")
}
```
---
## **Ejemplo completo con módulo y paquete personalizado**
```
// go.mod
module github.com/usuario/miapp

go 1.22
```
```
// saludar/saludar.go
package saludar

import "fmt"

func Hola(nombre string) {
    fmt.Println("¡Hola,", nombre, "desde el paquete saludar!")
}
```
```
// main.go
package main

import "github.com/usuario/miapp/saludar"

func main() {
    saludar.Hola("Mundo")
}
```
**Ejecutar**
```
go run .
```

## Extra: Importar dependencias externas
```
go get github.com/fatih/color
```
```
import "github.com/fatih/color"
```
