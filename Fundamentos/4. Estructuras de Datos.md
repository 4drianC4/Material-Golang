# Estructuras de Datos

## Arrays y Slices
## **Conceptos**
En Go, los **arrays** y **slices** son estructuras que almacenan colecciones de elementos del mismo tipo. Aunque similares, tienen diferencias importantes:
- Un **array** tiene tamaño fijo y forma parte del tipo.
- Un **slice** es una vista flexible y dinámica sobre un array. Es el tipo más comúnmente utilizado para trabajar con listas.
## **Datos clave**
- Los arrays se declaran con un tamaño fijo: `[5]int`
- Los slices se declaran sin tamaño: `[]int`
- Los slices pueden crecer dinámicamente.
- Se accede a los elementos con índices (`a[0]`)
- `len()` devuelve la longitud; `cap()` devuelve la capacidad (solo para slices).
- Go pasa arrays **por valor** y slices **por referencia al array subyacente**.
- Los slices pueden crearse a partir de arrays o con `make`.

---

## **Semántica / Estructura de Código**
### Declaración de un array
```
var numeros [3]int = [3]int{1, 2, 3}
```
### Declaración de un slice
```
nombres := []string{"Ana", "Luis", "Juan"}
```
### Slice a partir de un array
```
arr := [5]int{10, 20, 30, 40, 50}
sub := arr[1:4] // [20 30 40]
```
### Slice con make
```
datos := make([]int, 3, 5) // longitud 3, capacidad 5
```
### Agregar elementos a un slice
```
var lista []int
lista = append(lista, 10)
```
## Ejemplo completo
```
package main

import "fmt"

func main() {
    // Array
    var edades [3]int = [3]int{20, 25, 30}
    fmt.Println("Array:", edades)

    // Slice
    nombres := []string{"Ana", "Luis"}
    fmt.Println("Slice:", nombres)

    // Agregar elemento
    nombres = append(nombres, "Carlos")
    fmt.Println("Slice con append:", nombres)

    // Crear slice con make
    valores := make([]int, 2, 4)
    valores[0] = 1
    valores[1] = 2
    fmt.Println("Slice con make:", valores)

    // Sub-slice de un array
    a := [5]int{1, 2, 3, 4, 5}
    sub := a[1:4] // 2, 3, 4
    fmt.Println("Sub-slice de array:", sub)

    // Longitud y capacidad
    fmt.Println("len(sub):", len(sub))
    fmt.Println("cap(sub):", cap(sub))
}
```
**Salida esperada**
```
Array: [20 25 30]
Slice: [Ana Luis]
Slice con append: [Ana Luis Carlos]
Slice con make: [1 2]
Sub-slice de array: [2 3 4]
len(sub): 3
cap(sub): 4
```

## Maps
## **Conceptos**
Un **map** en Go es una estructura de datos que almacena pares **clave–valor**. Es similar a diccionarios en Python o objetos en JavaScript.
- Las claves deben ser de un tipo comparable (`string`, `int`, etc.)
- Los valores pueden ser de cualquier tipo.
- Se accede a los valores mediante la clave: `mapa["clave"]`
- El orden de los elementos **no está garantizado**.
## **Datos clave**
- Se declara con la sintaxis: `map[TipoClave]TipoValor`
- Se puede inicializar con `make()` o con una literal.
- Se pueden agregar, modificar, eliminar y consultar elementos.
- Se puede comprobar si una clave existe con el segundo valor de acceso (`valor, ok := mapa["clave"]`).
- Los maps son **referencias**, no copias.
## Semántica / Estructura de código
### Declaración e inicialización
```
edades := map[string]int{
    "Ana":   30,
    "Luis":  25,
    "Pedro": 35,
}
```
### Uso de make
```
paises := make(map[string]string)
paises["BO"] = "Bolivia"
paises["AR"] = "Argentina"
```
### Acceder y comprobar existencia
```
valor, ok := edades["Luis"]
if ok {
    fmt.Println("Edad de Luis:", valor)
} else {
    fmt.Println("No existe")
}
```
### Eliminar una clave
```
delete(edades, "Pedro")
```
## Ejemplo
```
package main

import "fmt"

func main() {
    // Crear map con valores
    edades := map[string]int{
        "Ana":   30,
        "Luis":  25,
        "Pedro": 35,
    }

    // Acceso directo
    fmt.Println("Edad de Ana:", edades["Ana"])

    // Verificar existencia
    if edad, ok := edades["Luis"]; ok {
        fmt.Println("Edad de Luis:", edad)
    } else {
        fmt.Println("Luis no está en el mapa")
    }

    // Agregar nuevo valor
    edades["Maria"] = 28

    // Eliminar valor
    delete(edades, "Pedro")

    // Iterar sobre el map
    for nombre, edad := range edades {
        fmt.Println(nombre, "tiene", edad, "años")
    }
}
```
**Salida esperada**
```
Edad de Ana: 30
Edad de Luis: 25
Ana tiene 30 años
Luis tiene 25 años
Maria tiene 28 años
```

## Strings y su manipulación
## **conceptos**
Un **string** en Go es una secuencia inmutable de bytes que representa texto codificado en UTF-8. Al ser inmutables, no se pueden modificar directamente, pero se pueden procesar, recorrer y construir nuevos strings.
Go ofrece funciones útiles en el paquete `strings` para buscar, reemplazar, dividir, unir, etc.
## **Datos clave**
- Un string se declara con comillas dobles: `"Hola"`
- La longitud de un string es el número de **bytes**, no necesariamente caracteres.
- Los strings son inmutables.
- Se puede acceder a los bytes con `s[i]`, pero devuelve un `byte`, no un `char`.
- El paquete `strings` y `strconv` son esenciales para manipular texto.
## Semántica / Estructura de código
### Declaración y acceso
```
mensaje := "Hola mundo"
fmt.Println(mensaje[0])        // 72 (byte de 'H')
fmt.Println(string(mensaje[0])) // "H"
```
### Concadenación
```
nombre := "Ana"
saludo := "Hola, " + nombre
```
### Funciones del paquete
```
import "strings"

strings.Contains("golang", "go")      // true
strings.ToUpper("golang")             // "GOLANG"
strings.ReplaceAll("a-b-c", "-", "+") // "a+b+c"
strings.Split("uno,dos,tres", ",")    // ["uno", "dos", "tres"]
strings.Join([]string{"a", "b"}, "-") // "a-b"
```
### Conversión de número a string y viceversa (strconv)
```
import "strconv"

n := 123
s := strconv.Itoa(n)          // "123"
i, err := strconv.Atoi("456") // 456
```
## Ejemplo
```
package main

import (
    "fmt"
    "strings"
    "strconv"
)

func main() {
    texto := "Hola mundo"

    fmt.Println("Original:", texto)
    fmt.Println("Mayúsculas:", strings.ToUpper(texto))
    fmt.Println("Contiene 'mundo'?:", strings.Contains(texto, "mundo"))
    fmt.Println("Reemplazo:", strings.ReplaceAll(texto, "mundo", "Go"))

    partes := strings.Split("a,b,c", ",")
    fmt.Println("Split:", partes)

    unido := strings.Join([]string{"Go", "Lang"}, "-")
    fmt.Println("Join:", unido)

    numero := 42
    textoNumero := strconv.Itoa(numero)
    fmt.Println("Número a string:", textoNumero)

    textoNum := "2025"
    num, _ := strconv.Atoi(textoNum)
    fmt.Println("String a número:", num)
}
```
**Salida esperada**
```
Original: Hola mundo
Mayúsculas: HOLA MUNDO
Contiene 'mundo'?: true
Reemplazo: Hola Go
Split: [a b c]
Join: Go-Lang
Número a string: 42
String a número: 2025
```
